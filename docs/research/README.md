# Research Notes

This directory preserves prior-art reviews, reproducibility findings,
experiment observations, and unresolved questions. Research notes are
non-normative: they can inform a decision, but they do not change project
architecture or implementation requirements by themselves.

Keep public facts, missing information, and project-specific conclusions
explicitly separated. Date a review when chronology matters. When the project
adopts a consequential conclusion, record the actual decision in an
Architecture Decision Record (ADR) and link back to the supporting research.
